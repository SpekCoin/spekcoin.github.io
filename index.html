Spek

Spek is a post-quantum, unbonded proof-of-stake ledger where every 30 seconds the network elects one block from the eligible miners by a draw nobody can predict or grind, with no hashing race, nothing locked or slashed.

Three things to know

No energy race

One draw per stake output per slot decides candidacy, and nobody can see a winner coming until its header is published. Honest operating cost is a node.

Each draw hashes the epoch's beacon with the height, the miner's key and a slot secret the miner committed before that beacon existed. There is no nonce to search, so faster hardware cannot improve a draw. How the election works

Post-quantum from day one

SQIsign for every signature (Level V for long-lived custody), public keys hidden behind hashes until spent, a versioned migration path.

SQIsign is a candidate in NIST's process, not a NIST standard, and the code has been reviewed only by AI models. Both facts are stated below and on every cryptography and security page. Cryptography

Time is the schedule

A block, or a deterministic null, exists for every slot since genesis; the chain never stalls and timestamps cannot be forged.

The header carries no timestamp: a block at height h is dated genesis plus 30h seconds. Nodes take time from an authenticated Roughtime quorum, and a slot with no winner gets a null block every node builds the same way. Time and the clock · Null blocks

Is this PoW or PoS?

Unbonded proof of stake, with a 45-day RandomX ticket phase that distributes the first coins.

After the first 45 days, a miner is eligible when its stake address holds one output worth at least 80% of the block reward, created at least a day before it counts. Coins are not locked or slashed: the output is an ordinary coin the miner can spend at any time, and spending it ends eligibility from the next block. During the first 45 days nobody holds coins yet, so eligibility is priced with a RandomX ticket per 3-day round instead. That is still not proof of work: the work buys eligibility for a round, never a block.

Where Spek is strong

  • no ASIC race;
  • no lock-up or slashing;
  • an ordinary computer is enough (the published minimum is 4 dedicated cores, 8 GB of RAM and an SSD);
  • one funded stake output keeps a key eligible for its whole 8.4-year horizon;
  • each stake unit gets exactly one draw per slot.

SQIsign is not a NIST standard

SQIsign is a Round 3 candidate in NIST's additional-signature process (advanced in May 2026, with about two years of evaluation ahead). "NIST security level 1" names a security category, not an approval.

Audited only by AI models

The founders used Claude AI models to build and audit Spek, and the code has been audited only by AI models (Claude). No independent human audit, cryptographer review, or SQIsign-author review took place before launch. Anthropic, the maker of Claude, is not a partner in this project and does not endorse it.
