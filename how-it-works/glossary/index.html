How it works

Glossary

The terms these pages use, in alphabetical order.

Beacon
A random value for one epoch, read from the chain's election seed a full epoch before that epoch starts. Every draw in the epoch is scored against it. No one can predict it until its source epoch has been produced. See The beacon.
Checkpoint
A block hash every 4,000 blocks that fixes history below it. A hard checkpoint is compiled into a release; a pin file adds newer ones between releases and must be signed by a threshold of checkpoint signers. A node with no history of its own trusts both. See The checkpoint barrier.
Confirmation
One more block on top of the block that holds a transaction, 30 seconds each. A transaction is confirmed, never settled: how many confirmations to wait depends on the attacker share you defend against. See Confirmations.
Draw
The one chance a funded stake address gets in a slot. It is a hash of the beacon, the height, the miner's key and its draw secret; the number it produces is its score.
Draw secret
A value only the key owner can compute, unique for each height, that a header reveals (written r_h; the header fields keep the names slot_reveal and slot_path). It is checked against the horizon root.
Draw secret root
A random 32-byte secret in the miner's key file, drawn from the operating system and independent of the signing key. Every draw secret is derived from it, and it is never published.
Election seed
A running value in which every block mixes in its winner's draw secret. Beacons are read from it.
Epoch
1,440 slots, 12 hours. Each epoch has one beacon.
Equivocation
Signing two different headers for the same slot with one key. The key's entry for that slot is evicted and a compact proof is passed on.
Horizon, horizon root
A horizon is 1,024 consecutive 3-day segments of a key's draw secrets, about 8.4 years. Its horizon root is the Merkle root of their chains, written C, built into the stake address before any beacon it will be drawn against exists. It fixes which draw secret is valid for each height. See Draw secrets.
Launch phase
The first 45 days, when eligibility comes from RandomX ticket records instead of coins.
Miner
A block producer. Mining here means submitting one candidate block per slot, not racing to find a hash.
Nothing at stake
The classic weakness of unbonded proof of stake: signing costs nothing and nothing can be slashed, so a key that held stake at a fork point can sign a branch from that point later, even after selling its coins. In Spek only restoration pins and checkpoints bound it.
Null block
The block every node builds identically when no candidate for a slot validates. See Null blocks.
Open launch
The public process that fills the genesis block with ticket records before the chain starts: the launch key every launch ticket is searched under, the sealed list of submissions, and the launch nonce that fixes the genesis. See The open launch.
Opening tranche
The part of a genesis allocation spendable once coinbase maturity has passed: 3% of each founder's share and the stewardship fund's first 1,500,000 coins. Later tranches unlock year by year. See Stewardship.
Restoration pin
A running node's own checkpoint: the block below which it never reorganises its chain. It trails the tip by 33–67 hours.
Round hash
In the launch phase, the block hash that keys one round of the RandomX ticket search.
Roughtime
A protocol in which servers return authenticated time. A node keeps its verified clock from a quorum of independent operators. See Time and the clock.
Score
The number a draw produces: how far the draw's hash sits from the centre of the 256-bit hash space. The highest score whose full block validates wins the slot.
Settled and unsettled
A slot is unsettled while it is being mined and settled once it closes, 30 seconds later. The words describe slots only; a transaction is confirmed.
Slot
A 30-second timeslot. Its number is the block height, so a block's time follows from its height.
Stake address
The address built from a miner's key and one horizon root. Each horizon of a key has its own stake address.
Stake output
The one output at a stake address, worth at least a stake unit and old enough, that makes a header eligible. See Eligibility.
Stake program
The 32-byte form of a stake address that a launch-phase ticket names.
Stake unit
One output worth at least the coin requirement: 80% of the block reward (40 coins while the reward is 50), never below 0.1 coin.
Ticket record
In the first 45 days, a record written to the chain that proves a key's launch-phase work and makes it eligible.
