How it works

Glossary

The terms these pages use, in alphabetical order.

Beacon
A random value for one epoch, read from the chain's election seed a full epoch before that epoch starts. Every draw in the epoch is scored against it. No one can predict it until its source epoch has been produced. See The beacon.
Commitment
The Merkle root of a miner's slot secrets, stored in its stake output before any beacon it will be drawn against exists. It fixes which slot secret is valid for each height.
Draw
The one score a stake output gets in a slot: a hash of the beacon, the height, the miner's key and its slot secret.
Election seed
A running value in which every block mixes in its winner's slot secret. Beacons are read from it.
Epoch
1,440 slots, 12 hours. Each epoch has one beacon.
Equivocation
Signing two different headers for the same slot with one key. The key's entry for that slot is evicted and a compact proof is passed on.
Miner
A block producer. Mining here means submitting one candidate block per slot, not racing to find a hash.
Null block
The block every node builds identically when no candidate for a slot validates. See Null blocks.
Roughtime
A protocol in which servers return authenticated time. A node keeps its verified clock from a quorum of independent operators. See Time and the clock.
Score
How far a draw's hash sits from the centre of the 256-bit hash space. The highest score whose full block validates wins the slot.
Round seed
In the seed phase, the block hash that keys one round of the RandomX ticket search.
Seed phase
The first 45 days, when eligibility comes from RandomX ticket records instead of coins. The name is only a label for this launch period. It is not the election seed, the slot seed or the round seed.
Settled and unsettled
A slot is unsettled while it is being mined and settled once it closes, 30 seconds later.
Slot
A 30-second timeslot. Its number is the block height, so a block's time follows from its height.
Slot seed
A random 32-byte secret in the miner's key file, drawn from the operating system and independent of the signing key. Every slot secret is derived from it, and it is never published.
Slot secret
A value only the key owner can compute, unique for each height, that a header reveals. It is checked against the commitment in the stake output.
Stake output
A funded output that makes a key eligible, and holds its commitment. See Eligibility.
Ticket record
In the first 45 days, a record written to the chain that proves a key's seed-phase work and makes it eligible.
